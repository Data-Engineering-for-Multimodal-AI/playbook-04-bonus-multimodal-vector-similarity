# Data licenses

This file lists the datasets and models this playbook uses, where they come from, and their licenses. The code in this repository is MIT-licensed. That license does not cover third-party data or models; each one keeps its own license, listed below.

## Datasets

| Dataset | Source | License | In this repo |
|---|---|---|---|
| Food-preparation videos (32 clips, `download.mp4` to `download (31).mp4`) | Created by the author with a Google generative video model | MIT (this repository) | `data/videos/` (54 MB) |
| Reference photos of finished bowls (7) | Created by the author with the same model | MIT (this repository) | `data/images/` (5.2 MB) |
| Delivery orders (500 records for three fictional restaurants) | Generated by the author | MIT (this repository) | `data/orders/multirestaurant_orders.jsonl` (476 KB). Not read by the code |
| Sample search queries | Written by `python src/utils/init.py --generate-queries` | MIT (this repository) | `data/sample_queries.json` (20 KB) |

## Models

Downloaded by torchvision on first use (about 45 MB) |
